# Exonos | Beyond the Code

Site institucional da Exonos.

Para publicar no GitHub Pages:
1. Crie um repositório público (ex.: exonos-site).
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Vá em Settings > Pages, escolha a branch main e a pasta / (root) e salve.
4. O site fica disponível em https://SEU-USUARIO.github.io/exonos-site/
